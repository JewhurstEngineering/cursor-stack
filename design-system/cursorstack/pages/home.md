# Home

Overrides [MASTER.md](../MASTER.md) for the landing page only.

## Pattern

App Store Style Landing, with a Minimal and Direct hero. This is a download page for a native Mac app, not documentation.

## Section order

1. Hero — headline, one short paragraph, download, three facts, and a tab-strip mock
2. What it does
3. Screenshots (settings, onboarding). Static. No carousel.
4. How it works — install, then use
5. Requirements
6. Privacy — what it can do, what it never does
7. Shortcuts
8. Footer disclaimer and a repeated download

## CTA

Primary action is **Download for Mac**, linking to the latest GitHub Release. Repeat it in the header and after the shortcuts. Do not send people to a pinned `1.0.9` zip.

## Hero images

Use the full-color logo and the real tab-strip, settings, tab menu, and group menu screenshots. Download buttons point at the zip, not the release page.

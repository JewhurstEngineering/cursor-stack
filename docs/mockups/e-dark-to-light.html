Know which agent needs you.

While a chat runs in one project, you’re usually working in another. The tab tells you when to come back.

Try the strip.

Agents are working in the background tabs. When one turns amber, click it and answer.

In the app, these are your real Cursor windows. CursorStack only moves them.

It moves windows. That’s all.

Switch without the mouse⌃⌥] next, ⌃⌥[ previous, ⌃⌥1 to ⌃⌥9 to jump. Change them in Settings.
Put it on any edgeTop by default, so Cursor’s search stays clear. Bottom, left, or right if you’d rather.
Keep your code to yourselfIt never reads files, changes Cursor, or uploads your screen. The only request it makes is a signed-update check on GitHub.
Close it any timeQuitting CursorStack leaves every Cursor window open, right where it was.
What you needmacOS 14 or newer on Apple silicon, and Accessibility permission so it can move windows. Notifications are optional.

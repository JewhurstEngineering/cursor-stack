CursorStack puts a tab strip on the Cursor windows you already have open. Click a tab to switch projects, and see which agent is waiting on you.

    Know which agent needs you.
    
    
    While a chat runs in one project, you are usually working in another. The tab tells you when to come back, without a notification if you’d rather not have one.
    
    
    
      
    billing-api 
    Chat running
    An agent in that window is working. Leave it alone.
    
      
    ios-app 
    Waiting on you
    It finished, or it wants an answer. One click brings that window forward.
    
      
    infra 
    Needs attention
    Something went wrong in that chat. Go and look.
    
    
    
  
    

    


    
  
    
    
    
      
    
        
    Put the strip on any edge.
